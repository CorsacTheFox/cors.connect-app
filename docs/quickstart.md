# Быстрый старт Cors.Connect

## Подключение

1. Откройте бота [@your_subscription_bot](https://t.me/your_subscription_bot) → раздел **«Добавить устройство»** → скачайте приложение по ссылке.
2. Установите приложение.
3. В боте, в мини-приложении Cors.Connect, нажмите **«Добавить подписку»** — в приложении в разделе **Xray** появятся ваши VLESS-подписки.
4. В приложении откройте **Настройки → Сервис Cors.Connect → Аккаунт** и нажмите кнопку авторизации через Telegram.
5. Выберите подключение (Whitelist Bypass или сервер из Xray-подписки) и нажмите **«Подключить»**.
6. Разрешите VPN-соединение и уведомления, если система попросит.
7. Дождитесь статуса **«Подключено»**.

Для отключения нажмите ту же кнопку ещё раз.

## Раздельное туннелирование

После подключения доступна настройка **Настройки → Сеть → Раздельное туннелирование** — выбирайте, какие приложения идут через туннель, а какие работают напрямую (режимы: выкл / только выбранные / все кроме выбранных).

## Режим туннеля (DC / Видео)

В **Настройки → Туннель → Режим туннеля** можно выбрать способ передачи данных для Whitelist Bypass: **DC** или **Видео**. Если связь работает нестабильно, попробуйте переключить режим.

## Проблемы?

- Нет подключения по Xray — обновите подписку в разделе **Серверы Xray**.
- Whitelist Bypass не работает — проверьте тариф «Обход БС» в @your_subscription_bot.
